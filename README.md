# Daftar Tugas Kuliah

Aplikasi web sederhana untuk mengelola daftar tugas kuliah, dibuat dengan TypeScript dan Vite.

**Demo:** https://USERNAME.github.io/todo-kuliah/

## Fitur
- Menampilkan daftar tugas
- Menambah, mengedit, dan menghapus tugas
- Status tugas (Belum Selesai / Selesai)
- Tampilan responsif

## Cara Menjalankan
```bash
git clone https://github.com/Dam-afk03/todo-kuliah.git
cd todo-kuliah
npm install
copy .env.example .env
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Environment Variables
Salin `.env.example` menjadi `.env`, lalu isi:

| Variabel | Keterangan |
|---|---|
| `VITE_APP_NAME` | Nama aplikasi |
| `VITE_APP_VERSION` | Versi aplikasi |

## Teknologi
TypeScript, Vite, npm, Git & GitHub
